# Philadelphia Lead Abatement Pros (Bootstrap)

Bootstrap build of Philadelphia Lead Abatement Pros. Content comes from the Astro repo
`philadelphia-lead-abatement-pros`; the builder, Bootstrap vendor files and fidelity CSS
come from `cleveland-lead-abatement-bootstrap`.

- Edit the phone number in `config/site.mjs`, then run `npm run build`.
- Page templates live in `source/pages.json` (route -> full HTML).
- Open `index.html` directly or `npm start` for a local server.
- Live preview: https://itsjavierlomelin.github.io/philadelphia-lead-abatement-bootstrap/
